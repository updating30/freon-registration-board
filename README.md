# 登録準備ボード（デモ）

- 設備工事会社の「第一種フロン類充塡回収業者」の登録準備を1画面で見せる、応募用のモックです。会社・数字・現場はすべて架空です。事実（要件・書類・手数料・登録後の義務）は、同じ親フォルダの `調べたこと_登録の要件.md` の出典から取っています。
- 開き方：`index.html` をブラウザで開くだけです（ビルド不要。フォントだけ Google Fonts を読みます）。状態の切り替えはこのブラウザの localStorage（キー `freon-board-v1`）にだけ残ります。
- `_check/` は受入基準の確認で撮ったスクリーンショットです。
